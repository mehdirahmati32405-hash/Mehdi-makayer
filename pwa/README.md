# گزارش شهروندی ملایر — PWA مرحله اول

این پوشه یک نمونه اولیه مستقل برای رابط کاربری اپلیکیشن است و کد ربات تلگرام را تغییر نمی‌دهد. فایل‌های PWA عمداً در شاخه جداگانه `pwa-phase1` اضافه شده‌اند تا سرویس فعال FadeHost که فرمان اجرای `python main.py` دارد، تحت تأثیر قرار نگیرد.

## محتوا
- `index.html`: رابط راست‌چین فارسی، فرم گزارش، لیست محلی و نمایش نمونه نقش شهروند/اپراتور/مدیر.
- `manifest.webmanifest`: مشخصات نصب PWA.
- `sw.js`: کش پوسته رابط برای بازدیدهای بعدی.
- `icon.svg`: آیکن اولیه.

## محدودیت‌های مهم
- فرم فقط در حافظه همان صفحه کار می‌کند و گزارش‌ها به سرور ارسال یا به‌صورت پایدار ذخیره نمی‌شوند.
- آمار و نقش‌های مدیریتی نمایشی‌اند؛ احراز هویت واقعی وجود ندارد.
- هیچ اتصال یا تغییری در ربات، فایل پایگاه داده، توکن‌ها یا متغیرهای محیطی ایجاد نشده است.
- برای نصب PWA باید این پوشه از طریق HTTPS میزبانی شود؛ بازکردن مستقیم فایل HTML برای service worker کافی نیست.

## مسیر امن ادامه
1. بازبینی رابط و نیازهای سازمانی.
2. انتخاب میزبانی وب جدا از سرویس ربات و اتصال دامنه/HTTPS.
3. طراحی API و احراز هویت نقش‌محور؛ هرگز اعتماد به انتخاب نقش سمت مرورگر.
4. بررسی محل ذخیره‌سازی پایدار گزارش‌های ربات قبل از هر اتصال داده‌ای.
5. آزمایش با داده ساختگی، سپس اتصال کنترل‌شده به پایگاه داده و ربات با ثبت رویداد و جلوگیری از گزارش تکراری.
6. تست نصب، حالت آفلاین، دسترس‌پذیری و امنیت قبل از انتشار عمومی.
